# Pardeep Kumar — Portfolio Website

Responsive single-page portfolio built with plain HTML, CSS and JavaScript. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a repository named `pardeepk21.github.io`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, visit `https://pardeepk21.github.io/`.

Your LinkedIn, Behance, Instagram, YouTube and email links are already configured in `index.html`.
