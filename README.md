# Pardeep Kumar — Portfolio Website

Responsive single-page portfolio built with plain HTML, CSS and JavaScript. The Selected Work section includes embedded YouTube showreels and links to VFX, film and Behance projects.

## Publish with GitHub Pages
1. Create/use the repository `pardeepk21.github.io`.
2. Upload `index.html` to the repository root (replace the previous version).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, visit `https://pardeepk21.github.io/`.

Social profiles and email are already configured. YouTube videos are embedded using privacy-enhanced YouTube embeds.
